# rag — 검색 증강(RAG) 모듈

분석에 앞서 관련 법령·사례를 찾아 모델 컨텍스트에 넣고, 분석 뒤에는 판정된 항목에 근거를 붙인다.

> **범위**: `rag/**`
> **상위**: [AI API README](../README.md) · **연관**: 데이터 형식 → [`data/README.md`](../data/README.md)
> **여기 없는 것**: 함수 시그니처, 상수값, 키워드 목록, 우선순위 순서 — 전부 코드가 답한다.

---

## 관통 흐름 — 검색은 두 단계다

순서가 핵심이다. 뒤바뀌면 안 된다.

1. **키워드 감지** — 등기부 텍스트에서 위험 신호를 먼저 찾는다.
2. **벡터 검색** — 감지된 신호로 쿼리를 만들어 유사한 청크를 가져온다.

키워드가 하나도 걸리지 않으면 **일반적인 기본 쿼리로 폴백**한다. 그래서 **쿼리가 비는 경우는 없다.**
결과까지 보장되지는 않는다 — 저장소가 비어 있으면 빈 컨텍스트로 진행한다.

검색은 분석 **전후로 두 번** 쓰이며 목적이 다르다.

| 시점 | 목적 |
|---|---|
| 분석 전 | 모델에게 줄 컨텍스트 확보 |
| 분석 후 | 판정된 항목에 근거(법령·사례) 부착 |

분석 후 검색은 **위험이 치명적인 항목부터** 처리한다. 순위 자체는 코드가 갖는다.

---

## 불변식

- **검색 실패가 분석을 중단시키지 않는다.** 저장소 초기화나 조회가 실패하면
  검색 없이 모델 단독으로 분석한다. 검색은 품질 보조이지 필수 경로가 아니다.
- **데이터셋이 바뀌면 저장소를 다시 만든다.** 로더가 데이터셋 파일의 지문을 컬렉션 메타데이터에 남기고,
  서버가 뜰 때 지문이 다르면 저장소를 지우고 새로 채운다. 배포 서버의 저장소는 도커 볼륨에 남아 있으므로,
  이 장치가 없으면 데이터를 고쳐도 옛 내용이 계속 나간다. 지문이 같으면 저장소를 그대로 쓴다.
- **저장소는 프로세스마다 파일을 잡는다.** 워커를 여럿 띄우면 충돌한다.

## 재현성과의 긴장 — 이 모듈의 가장 중요한 사실

이 모듈에는 **외부 지식을 주기적으로 수집해 저장소에 반영하는 경로**가 있다.
스케줄러가 정해진 시각에 돌며, 실행 시각은 환경 변수로 조절한다.

분석 호출 자체는 무작위성을 제거해 재현 가능하게 만들어 두었지만,
**검색된 컨텍스트가 달라지면 결과도 달라진다.**

> 따라서 "같은 입력에 같은 결과"는 **지식 저장소가 그대로일 때만** 성립한다.

지식이 갱신되면 상류의 캐시에 남은 옛 결과와 새 분석이 섞일 수 있다.
지식을 의도적으로 갱신했다면 캐시를 함께 점검한다.

## 자동 갱신 — 지금은 꺼져 있다 (2026-09-27)

**기본값은 꺼짐이다.** `RAG_AUTO_UPDATE=true` 일 때만 스케줄러를 등록한다.

끈 이유: 자동 수집은 뉴스 제목·요약과 법령을 모델이 청크로 바꿔 **사람 검토 없이** 저장소에 넣고,
그 청크가 결과 화면의 "참고한 법령과 사례"로 그대로 나간다. 같은 날 사람이 넣은 데이터에서도
조문 오인용과 낡은 기준이 원문 대조로 여럿 드러났다 — 검토를 거치지 않는 경로는 정확성을 보장할 수 없다.

**다시 켜기 전에 필요한 것** (계획, 미구현): 수집 결과를 저장소가 아닌 검토 대기함에 두고 승인한 것만 반영,
법령은 모델 요약 대신 국가법령정보센터 원문을 그대로 쓰기, 결과 카드에 출처와 확인 날짜 표시.

### 자동 갱신을 넣었던 이유

**사기 수법이 계속 바뀌기 때문이다.** 고정된 지식만 두면 최근 사례를 반영하지 못하고,
분석이 과거의 패턴만 보게 된다. 새로 드러난 수법을 근거로 쓰려면 지식이 따라와야 한다.

**대가가 위의 "재현성과의 긴장"이다.** 최신성을 얻는 대신, 같은 입력의 결과가
지식 갱신 시점을 경계로 달라질 수 있다. 둘 다 가질 수는 없어 최신성을 택했다.

그래서 재현성은 **포기한 것이 아니라 조건부**다 — 분석 호출 자체의 무작위성은 제거해 두고,
달라질 수 있는 요인을 지식 갱신 하나로 좁혀 놓았다.

---

## 감지 키워드를 손댈 때

키워드는 검색 쿼리를 좌우하고, 검색 결과는 모델이 보는 컨텍스트를 좌우한다.
**늘리거나 줄이면 분석 서술이 바뀐다.** 목록은 코드에 있으므로 여기서 복제하지 않는다.

바꾸기 전에 위 "재현성과의 긴장"을 먼저 읽는다.
